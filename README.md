# 📝 Formulário de Matrícula
### Página web simples para inscrição de alunos


---

## 📖 Sobre o Projeto
Este projeto é uma página estática desenvolvida em **HTML e CSS** que apresenta um formulário de matrícula.  
O objetivo é praticar conceitos de front-end, como criação de formulários, estilização e organização de layout.

### 🎥 Demonstração
👉 [Visualizar Projeto no GitHub Pages](https://dodogm.github.io/Formulario-de-Matricula/)  


### 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- Git & GitHub
